## 🧠 Sobre o Projeto
Este projeto implementa um CRUD focado no gerenciamento de livros.  
Ele foi desenvolvido com o objetivo de praticar lógica, organização de código e manipulação de dados em memória ou arquivo.

O usuário pode registrar livros, visualizar a lista completa, alterar registros existentes e remover itens.

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Função |
|-----------|--------|
| **JavaScript** | Lógica e gerenciamento de dados |
| **Node.js** *(execução via console)* | Rodar a aplicação |
| **Git & GitHub** | Versionamento e histórico do projeto |

---

## 📌 Funcionalidades

| Função | Descrição |
|-------|-----------|
| Cadastrar Livro | Adiciona um novo livro ao sistema |
| Listar Livros | Exibe todos os livros registrados |
| Atualizar Livro | Permite editar um livro existente |
| Remover Livro | Exclui um livro do sistema |
| Menu Interativo | Navegação simples pelo console |
